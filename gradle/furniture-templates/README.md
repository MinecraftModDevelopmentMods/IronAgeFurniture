# Upholstered furniture models

These are Iron Age Furniture's bed, wingback-chair and throne models by
FoxNekitsune, carried forward from the Forge 1.12 release. They retain the original
geometry and camera transforms. No other mod's assets are included.

`updatePhaseFourUpholsteryCatalog` converts their old vanilla texture names and
generates the Minecraft 1.14 models, blockstates, recipes and English names.
Each wood uses its existing chair textures; each upholstery colour uses vanilla
wool, so resource packs can replace either independently.

Edit these templates to change shared geometry, then run the update task. Normal
builds check the generated files without rewriting them.
